## 接口

- 画具全在 `src/props.js` 文件头：墨板 `dsSlate`、干净的线 `dsPath` / `dsArrow` / `dsBox` / `dsCircle` / `dsDot` / `dsBrace`、字 `dsText` / `dsMono` / `dsCode` / `dsWindow`、变形 `dsMorph`、强调 `dsBump`。书页上的东西照旧用 kit.js（`cutPaper`、`rline`、`zh`）。
- 颜色只用 `DC` 里的，一种颜色一件事（见 props.js 文件头）。墨板上的线不抖（`dsPath`），书页上的线抖（`rline`）。
- 站位：中墨板时两人在 `DS.ran`（x 292，连尾巴约 x 92–492）/ `DS.pch`（x 1632，约 x 1507–1757），脚底 y=880；内容只放在墨板 `DS.slate` 里。满墨板时两人在 `DS.ranS` / `DS.pchS`（身高 300），内容避开两个下角（x<340 或 x>1580 且 y>560）。
- 台词用 `dsSeq`，默认说话人八云蓝；帕秋莉写 `{ who: 'patchouli' }`。蓝的表情 normal / happy / surprised / awkward / proud，姿势 stand / read / point / present / think / bow；帕秋莉见 `src/character/patchouli.js` 文件头。
- 每段 `scene({ …, noFlip: true })`，段首段末各留 ≥ 0.4 秒只画交接画面（`dsHo*`），拼起来看不出接缝。
- 字幕区 y≈930–1030，墨板底边 ≤ 906，不放字。屏幕上只写正在念的关键词。
- 顶层名字带段前缀；只改自己的段文件；台词不改字（改了要重跑 `npm run voice`）。
- 不用 `Math.random()`、不用 `c.filter`、不存状态。
