## 接口

- 画风和每段的画面见 `docs/分镜.md`；样板是 `src/scenes/1-loop.js`，照它的写法：`dsPage` 铺纸 → 画本段的东西 → `dsCast` 画人物。
- 画具在 `src/props.js` 文件头有清单；kit.js 的 `cutPaper` `rline` `arrow` `zh` `thread` `brassPin` `popup` `pop` 照常用。亮点特效 `src/fx/popup-stand.js` 的 `fxPopAngle`（立起曲线）、`src/fx/ice-slabs.js` 的 `fxIceSquash`（落地压扁）可以直接调。
- 站位：八云蓝 `DS.ran`（右边，x 约 1470–1830，脚底 y=900），帕秋莉 `DS.pch`（左边，x 约 130–340），内容区 x 90–1430、y 150–880。帕秋莉在场时左边 x<380 空出来。字幕区 y≈930–1030。
- 台词用 `dsSeq`（默认八云蓝说，帕秋莉写 `{ who: 'patchouli' }`）。时刻用 `dsWordT(行, '词')` 对齐到念到某个词。台词文字不改（改了要重跑 `npm run voice`），`pause` / `hold` 可以微调。
- 每段 `scene({ …, noFlip: true })`。段首、段末各 ≥0.4 秒只画交接画面（`dsHo*`），交接画面里的人物用标准站位。
- 顶层名字带段前缀；只改自己的段文件。不用 `Math.random()`、不用 `c.filter`、不存状态。

## 验收

每段：`node tools/overlap.mjs --scene 段名` → `node tools/frames.mjs --scene 段名 --grid 30` → 看图，再用 `--at` 抽关键句的整帧。
全片：`npm run voice && npm run render`。
