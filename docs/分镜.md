## 画风（照第 1 集 patchouli-lecture-1）

- 整页暖色旧纸（`dsPage`），左上角页眉「第 N 页 · 名字」。开场和结尾是摊开 / 合上的魔导书（`spread`）。

- 一页一种压暗的颜色做强调，其余是纸、墨、灰。字少：屏幕上只写正在念的关键词。
- 八云蓝站在右边讲（`DS.ran`，x 约 1470–1830），帕秋莉在她自己的台词里从左边走进来（`DS.pch`，x 约 130–340），说完退出去。内容放在 x 90–1430；帕秋莉在场时左边 x<380 空出来。人物不和纸片、字重叠。

## 2 阶梯（ladder）

| 台词 | 画面 |
|---|---|
| 想改一个 harness 的行为，有三级做法。 | agent loop 纸片飞到右上角候着；三级纸台阶依次「啪」地立起（暗着） |
| 第一级，声明式扩展：skill、MCP、settings 里的 hook。 | 第一级亮起 |
| 它们只能给 harness 喂材料：多一段说明，多一个工具，多一个外部脚本。 | 台阶上方一个 harness 纸盒，三张纸条（说明 / 工具 / 脚本）沿箭头喂进去，盒子本身不变 |
| 帕：我改了一个 skill，要重启才生效吗？ | 「SKILL.md」纸条上铅笔改了一行 |
| 不用。skill 就是一个文本文件，下次读的时候就生效了。 | 一根「下次读取」的箭头，打勾 |
| 第二级，进程内中间件：pi 的 extension，Claude Code 的 mod。 | 第二级亮起；第一级的两张小纸条（能改 / 地基）贴上 |
| 它们跑在 harness 的进程里，能拦截、改写官方预留的事件。 | harness 纸盒打开：里面一条事件管道，管道上几个预留的口子 |
| 拿 Claude Code 的 mod 来说：同一个事件的处理器，串成一条链。 | 事件 `tool.call` 走进一串处理器纸片 |
| 每一个处理器都能决定：调用 next 往下传，或者就地拒绝。 | 前两个 next 放行，第三个 deny 打回；旁边一张 CC 文档里的代码纸 |
| 而且 Claude 能自己写 mod。你点头之后，当前会话就加载，不用重启。 | 新处理器一个字一个字写出来，盖一个「同意」朱印，插进链里 |
| 帕：这已经很强了。还缺什么？ | — |
| 缺在「官方预留」这四个字上。口子是官方挖的，循环本身不在口子里。 | 拉远：口子都在盒子外沿；盒子里的 loop 被钉死 |
| 第三级，可组合内核，就是 DSH：连 agent loop 都是一个能换掉的插件。 | 第三级亮起；agent loop 纸片落到第三级上，被抽出来换成另一张、再换回来 |
| 越往上，能改的越多，需要的地基也越重。 | 三级的「能改 / 地基」纸条全出，第三级高亮（= `dsHoStairs`） |

## 3 Cordis（cordis）

| 台词 | 画面 |
|---|---|
| 帕：连循环都能换……拔错一个，不就全乱了？ | 第三级台阶变成插件树的根，一棵钉在纸上的树长出来：纸片 + 图钉 + 线 |
| 难点就在这儿：插件在进程里是有状态的。 | 推近一个插件 `test-gate` |
| 它注册了工具，挂了监听器，还被别的插件依赖着。 | 它身上贴出三张符（注册工具 / 监听事件 / 副作用）；另一个插件用线连着它 |
| 要是直接拔掉，这些注册还留在原地，就成了悬空引用。 | 硬拔：插件被扯走，符还挂着，线头悬空 |
| 帕：就像撤掉一个式神，贴出去的符也要一张张收回来？ | 倒回去 |
| 正是。Cordis 管这叫可逆副作用：每一次注册，都附带一张撤销的符。 | 每张符翻过来，背面写「撤销」；旁边 `register()` 返回撤销函数的真代码 |
| 插件卸载时，按相反的顺序，一张张揭掉。这是时间上的可组合。 | 下面一根时间线，符按 1、2、3 贴上，卸载时 3、2、1 揭掉；标「时间」 |
| 第二件事，叫依赖响应。插件用 inject 写明自己要哪些服务。 | 插件 `consumer` 挂着 `inject = ['greeter']`，一根线连到服务 `greeter` |
| 服务到齐才启动；服务一走，依赖它的插件先停下，等它回来再重新加载。 | greeter 拿走 → 线松垂、consumer 变灰「等待」；greeter 回来 → 重新亮起 |
| 这是空间上的可组合。Cordis 的论文，题目就叫时空可组合性的编程范式。 | 标「空间」；一张论文纸条（英文题目 + arXiv 号） |
| 帕：这套东西，是为 agent 发明的？ | — |
| 不是。它来自 Koishi：4.7 版把核心框架独立出来，取名 Cordis。 | 左边一棵小树「Koishi」，根也是 Cordis |
| Koishi 的插件本来就要支持热重载，卸载时必须清掉所有副作用。 | Koishi 树上卸下一个插件，符一张张揭掉 |
| DSH 把 Cordis 的源码整个收进了自己的仓库。 | Cordis 的根复制一份嵌进 DSH 树底下，标 `vendor/cordis`；整棵树压成一块地基板（= `dsHoSlab`） |

## 4 自进化（evolve）

| 台词 | 画面 |
|---|---|
| 帕：地基有了。agent 是怎么「学会」新本事的？ | 底下一块 Cordis 地基板 |
| 分两步。第一步叫 PTC 模式：模型写一小段程序，把现有的工具组合起来。 | 第二块板「PTC 模式」落下（压扁再弹回）；一张 `run_code` 代码纸用线串起几个工具纸片 |
| 程序里每调用一次工具，照样走完整条检查流程。 | 每根线经过一道小闸门「检查」 |
| 第二步叫创造模式：模型写一个全新的插件，装进插件树。 | 第三块板「创造模式」落下 |
| 动手之前，它先用只读的检查工具，查清运行时有哪些服务和事件。 | 放大镜扫过地基板，冒出 `cordis_inspect_list` / `cordis_inspect_query` |
| 再把插件写成工作区里的文件，交给 Plugin Manager 安装。这一步要你批准。 | 几张文件纸 → `plugin_manager · install_bundle` → 「批准」朱印 → 新插件嵌进板里 |
| 帕：那 Cordis 就是进化算法了？ | — |
| 不是。Cordis 只是地基：保证装上、拆下都干净。 | 地基板亮一下 |
| 真正的进化循环，是社区写在上层的插件，比如 auto-evolve 和 evolver。 | 第四块板「进化循环」落在最上面，上面一个循环箭头 |
| 它们有个共同点：验证器，放在可进化的集合之外。 | 虚线圈住上面几层「可进化」，「验证器」纸盒在圈外 |
| 帕：不然 agent 会顺手改掉考它的那张卷子。 | 循环箭头伸向验证器 |
| 对。会改自己的系统，第一件要锁住的，就是判断它改得好不好的那一块。 | 一把挂锁扣上，箭头被挡回；结尾几块板变成三张窗口标题条（= `dsHoTrio`） |

## 5 同题三解（demo）

| 台词 | 画面 |
|---|---|
| 来做个对比：同一个需求，三个 harness 各做一遍。 | 三张标题条往下长成三个窗口：Claude Code / pi / DSH |
| 需求是：测试连续失败三次以后，拦下第四次，让 agent 先写下失败原因。 | 顶上一张需求纸条：✗ ✗ ✗ → 第四次被拦 |
| Claude Code：让 Claude 写一个 mod，挂在工具调用事件上，数失败次数，第四次直接拒绝。 | 左窗口打出 `on('tool.call', …)` / `return { deny }`；底下「本会话热加载（要你同意）」 |
| pi：写一个 extension，在工具调用时返回 block 和原因，放进目录，reload 一下。 | 中窗口 `pi.on("tool_call", …)` / `{ block: true, reason }`；底下 `.pi/extensions/` · `/reload` |
| DSH：agent 先查运行时，找到工具执行前的那个事件，再自己写插件、自己装上。 | 右窗口：`cordis_inspect_query` → `tools/pre-execute` → 插件代码 → `install_bundle` |
| 帕：三家都做到了。那 DSH 的看点在哪？ | 三个窗口各打一个勾 |
| 在出错以后。我们故意写错一个插件：漏掉一句 next。 | 左中两个窗口退下；DSH 展开成一条 `tools/pre-execute` 事件链（几个监听器 → 默认放行 → 执行）；坏插件的 `return next()` 被划掉 |
| 链条断在这一层：后面的监听器和默认的放行全被吞掉，工具一个都跑不起来。 | 小纸圆片走到坏插件就停住、越堆越多；后面的纸片全变灰 |
| 把它卸载。它注册的监听器和工具按相反的顺序撤销，其余工具恢复正常。 | 坏插件身上的符倒序揭掉，链条接上，纸圆片流过去 |
| 再重启一次。只活在内存里的动态定义，会被清空。 | 「重启」；一张虚线的「动态定义」纸片消失 |
| 经 Plugin Manager 装进配置的插件，重启以后还在。 | 一张钉在 profile 上的插件纸片还在原位 |
| 最后把整棵插件树打印出来：agent loop，只是其中一行。 | `dsh --profile web --dump-config` 打出一张 YAML 纸，`- id: agent-loop` 那行高亮（= `dsHoRow`） |
