## 简介

Koishi 让人在运行时给 bot 装插件，DeepSeek Harness 让 agent 在运行时给自己装插件。八云蓝主讲、帕秋莉提问，8 分半讲三件事：harness 的扩展能力分三级（声明式 → 进程内中间件 → 可组合内核）；第三级要靠 Cordis 的可逆副作用和依赖响应打地基；地基不等于进化算法，验证器得放在能进化的东西外面。
